# OpenPuzzle 1.0.60 — Shared desktop and Windows GPU support

The desktop makes buttons, checkboxes and field arrows easier to see in the
light and dark themes. Both platforms use the same Qt widgets and styles.

The Linux x86_64 packages are `OpenPuzzle-1.0.60-Linux-x86_64.deb` and
`OpenPuzzle-1.0.60-Linux-x86_64.tar.gz`. The portable updater package is
`OpenPuzzle-1.0.60-portable-XXXXXXXX.deb`, with the first eight characters of
the Debian package SHA-256 in place of `XXXXXXXX`.

On Windows, select a device and benchmark BitCrack CUDA, BitCrack OpenCL or
KeyHunt CPU before starting work. Safe Stop finishes the current range before
exiting. Telemetry and hardware controls depend on the card and its driver.

For Windows x64, run `OpenPuzzle-1.0.60-Windows-x86_64-Setup.exe` and open
**OpenPuzzle 1.0.60** from the Start menu, or extract
`OpenPuzzle-1.0.60-Windows-x86_64.zip` and open `Start.cmd`.
The Windows desktop uses NVML for NVIDIA and ADLX for AMD through the
installed graphics drivers.
Windows Vanity integration remains in testing for a future release.
