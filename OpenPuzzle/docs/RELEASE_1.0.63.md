# OpenPuzzle 1.0.63 — Support diagnostics

Open **Messages** and select **Copy diagnostics** to copy a report for support.
It includes the OpenPuzzle version, GPU models and drivers, the selected
execution mode, current range status and recent diagnostic codes. The report
omits raw logs, device identifiers, local paths and private key material.

The feature is available in the shared Linux and Windows desktop. The Windows
installer and portable ZIP include Vanity CUDA and the recovery fixes from
1.0.62.
