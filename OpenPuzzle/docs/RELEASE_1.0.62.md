# OpenPuzzle 1.0.62 — Vanity recovery on Windows

Choose **Recover** after **Stop now** to resume a Vanity range with a valid
lease. If the coordinator confirms that the assignment has expired or is
missing, OpenPuzzle archives the local checkpoint and requests a new range.
The desktop log shows where the archive was saved.

Windows x64 downloads include Vanity CUDA.

- `OpenPuzzle-1.0.62-Windows-x86_64-Setup.exe`
- `OpenPuzzle-1.0.62-Windows-x86_64.zip`

Linux x86_64 downloads

- `OpenPuzzle-1.0.62-Linux-x86_64.deb`
- `OpenPuzzle-1.0.62-Linux-x86_64.tar.gz`
- `OpenPuzzle-1.0.62-portable-XXXXXXXX.deb` for the built-in updater.

Before updating, click **Safe Stop** and wait for the active range to finish.
After installing on Windows, open **OpenPuzzle 1.0.62** from the Start menu.
For the portable ZIP, extract all files and open `Start.cmd`.
