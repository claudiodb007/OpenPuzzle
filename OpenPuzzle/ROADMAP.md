# OpenPuzzle Roadmap

This document describes the planned evolution of the OpenPuzzle platform.

---

## Version 0.30

Current development phase.

### Goals

- Improve Service Layer
- Improve Worker Management
- Improve Execution Queue
- Continue architecture documentation

---

## Version 0.40

### Goals

- Dispatcher
- Worker Agent
- Automatic heartbeats
- Autonomous Scheduler

---

## Version 0.50

### Goals

- Console Dashboard
- REST API
- Statistics and reporting

---

## Version 0.60

### Goals

- Multi-machine support
- Distributed workers
- Cluster management

---

## Version 1.0

### Goals

- Plugin system
- Web dashboard
- Stable public API
- Production release

---

The roadmap will evolve as OpenPuzzle grows.
